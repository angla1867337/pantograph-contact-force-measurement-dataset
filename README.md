# Pantograph contact-force measurement dataset

This repository contains the numerical data supporting the manuscript:

> **Observer-Assisted Indirect Measurement of Pantograph–Catenary Contact Force: Predictive Uncertainty and Decision-Level Validation**  
> Shenglan Chen, Zhaohui Tang, Yongfang Xie, and Hu Zhang

The files document the complete numerical evidence chain used in the manuscript: observer-assisted contact-force reconstruction, uncertainty propagation and coverage, threshold-based decisions, sensitivity studies, robustness tests, and controller comparisons.

## Scope and scientific status

- All files in this repository were generated by the numerical studies reported in the manuscript.
- The repository contains **numerical/synthetic results, not measurements from a physical pantograph test bench or railway field test**.
- Third-party experimental datasets, papers, source models, analysis scripts, manuscript source files, figures, and PDFs are not included.
- The dataset supports reproduction of the reported tables and figures from the stored numerical outputs. Re-running the simulations requires the separate research code, which is outside the scope of this data-only repository.

## Repository structure

```text
data/
├── force_validation_traces/              # 30 held-out validation trajectories (seeds 01–30)
├── force_method_baselines*.csv           # Raw, low-pass-filtered, and observer comparisons
├── force_predictive_coverage*.csv        # Predictive uncertainty and k=2 coverage results
├── force_direct_decisions*.csv           # Decision metrics at the illustrative H = 60 N threshold
├── force_threshold_sweep*.csv            # Decision sensitivity for H = 30–80 N
├── force_gum_mc.csv                       # GUM-style and Monte Carlo uncertainty comparison
├── force_extended_budget*.csv            # Extended uncertainty-budget results
├── force_calibration_covariance.csv       # Calibration covariance used by the reconstruction study
├── measurement_*.csv                     # Reconstruction, sampling, noise, and mismatch studies
├── beta_sensitivity*.csv                  # Observer-parameter sensitivity
├── state_event_source_ablation*.csv       # State/event-source ablation results
├── unseen_irregularity_*.csv              # Held-out irregularity profiles and robustness results
├── structural_perturbation_robustness.csv # Structural-parameter perturbation study
├── phase10/11/12_*.csv                    # Controller and severity-map numerical studies
├── matched_*.csv                          # Matched controller baselines
└── force_validation_protocol.json         # Key numerical validation settings and checks
```

Files ending in `_summary.csv` contain aggregate statistics. Their companion files contain run-level or condition-level results. Unless a column explicitly states otherwise, reported `mean` and `std` values are computed over the independent numerical seeds used in the corresponding study.

## Core datasets

| File or group | Description |
|---|---|
| `force_validation_traces/seed_*.csv` | Time histories of true and reconstructed states and contact force for 30 held-out trajectories. |
| `force_method_baselines.csv` | Seed-level comparison of raw sensing, low-pass filtering, and observer-assisted reconstruction. |
| `force_predictive_coverage.csv` | Seed-level RMSE, predictive standard uncertainty, coverage, and normalized error. |
| `force_direct_decisions.csv` | Alarm, false-positive, false-safe, indeterminate, and event-timing metrics at `H = 60 N`. |
| `force_threshold_sweep.csv` | Decision-level results for `H = 30, 40, 50, 60, 70, 80 N`. |
| `measurement_uncertainty_budget.csv` | Input uncertainty, sensitivity coefficient, and standard contribution for each uncertainty source. |
| `measurement_reconstruction_trace_seed11.csv` | Representative time trace used to illustrate state and force reconstruction. |

## Units and conventions

- Time: seconds (`s`) or milliseconds (`ms`) as stated in the column header.
- Contact force and force error: newtons (`N`).
- Displacement: metres (`m`), unless otherwise stated.
- Acceleration: metres per second squared (`m/s^2`).
- Rates, coverage, disagreement, and indeterminate fractions: percent (`%`).
- `uc` denotes combined standard uncertainty.
- `k2 coverage` denotes the fraction covered by the interval formed with coverage factor `k = 2`.
- `false-safe` is the manuscript's missed-alarm measure: the reconstructed decision is safe while the reference decision is alarm.
- `H` is an illustrative numerical decision threshold, not a railway safety or conformity limit.

## Recommended entry points

For a compact review, start with:

1. `data/force_method_baselines_summary.csv`
2. `data/force_predictive_coverage_summary.csv`
3. `data/force_direct_decisions_summary.csv`
4. `data/force_threshold_sweep_summary.csv`
5. `data/measurement_uncertainty_budget.csv`

The run-level companion files should be used for independent recalculation of the summary statistics.
